## 密钥与开关

使用仓库 Actions Secrets 中已有的 `CONTENT_API_KEY`、`CONTENT_API_BASE_URL`、`CONTENT_MODEL`；这些值不应写入代码、日志、图片或 APK。完整版 1.2 默认使用上述公开内容地址，手机只下载内容，不使用维护者的模型 API 密钥。

仓库变量 `AUTO_CONTENT_ENABLED=false` 可暂停完整版自动生成；其他值或缺省按仓库所有者的上线要求启用。复刻仓库不自动消耗本仓库额度。

## 手机版

联网启动、恢复前台及定时检查时增量同步；常规检查有一小时节流，失败至少 15 分钟后重试，也可在“我的”中立即检查。已关闭自动同步的用户偏好不被重置。笔记、收藏、答题和计划不因同步被删除。安装旧 1.1 的用户需先更新到 1.2，或自行在“我的”设置上述内容地址。

这里的“自动更新”指学习内容，不会静默安装新的 APK。内容目前公开分发，支付、会员鉴权和收费后访问尚未上线。来源和结构检查不等于人工逐条审校；AI 练习不是考试真题。

浙江材料优先使用省政府官网；官网网络受阻时使用浙江在线（浙江省委省政府新闻门户）的近期省内报道，来源按实际发布网站展示，不伪称省政府原文。不接受站外链接、超过 31 天或未来日期、无可核对正文的材料。抓取备用通路仍验证 HTTPS 证书，不会禁用 TLS 检查。
