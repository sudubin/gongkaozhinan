# 浙江完整版自动更新

完整版内容与开源版隔离，公开内容地址为：

`https://raw.githubusercontent.com/sudubin/gongkaozhinan/main/public/content/full/latest.json`

每日计划北京时间 07:17 执行（GitHub 调度可能延迟）。全国时政、浙江时政、浙江省情、常识、成语、申论六个方向各最多新增 5 条，即每日最多 30 条；质量检查、官方来源连通性、去重和模型输出可能导致实际数量更少，不承诺每天凑满。每方向每日最多 3 次请求，重跑继承当天额度。每次模型调用前先提交并推送预算记录，推送失败不继续调用；成功批次逐批保存，失败不会清空旧内容。

首次部署保留开源版已有的 104 条内容，加上 6 条浙江基础内容，共 110 条；完整继承旧版当天的调用记录，不重置已用额度。旧开源版内容地址、源码、下载和历史版本保留，旧每日任务停止。旧任务仅供维护，需要单独启用 `LEGACY_OPEN_SOURCE_CONTENT_ENABLED=true` 才可手动执行。

## 密钥与开关

使用仓库 Actions Secrets 中已有的 `CONTENT_API_KEY`、`CONTENT_API_BASE_URL`、`CONTENT_MODEL`；这些值不应写入代码、日志、图片或 APK。完整版 1.2 默认使用上述公开内容地址，手机只下载内容，不使用维护者的模型 API 密钥。

仓库变量 `AUTO_CONTENT_ENABLED=false` 可暂停完整版自动生成；其他值或缺省按仓库所有者的上线要求启用。复刻仓库不自动消耗本仓库额度。

## 手机版

联网启动、恢复前台及定时检查时增量同步；常规检查有一小时节流，失败至少 15 分钟后重试，也可在“我的”中立即检查。已关闭自动同步的用户偏好不被重置。笔记、收藏、答题和计划不因同步被删除。安装旧 1.1 的用户需先更新到 1.2，或自行在“我的”设置上述内容地址。

这里的“自动更新”指学习内容，不会静默安装新的 APK。内容目前公开分发，支付、会员鉴权和收费后访问尚未上线。来源和结构检查不等于人工逐条审校；AI 练习不是考试真题。
