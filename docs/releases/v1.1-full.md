## 本次更新

- 保留浙江时政、浙江特色省情以及全国时政、常识、成语、申论和速算。
- 内置 106 条学习卡、81 道原创练习，其中浙江时政 3 条、浙江省情 3 条；首次打开无需先填写 API 即可学习。
- 增量内容同步按稳定标识与修订号合并，保留原有笔记、收藏、作答和复习记录。
- 更新设置明确区分“本地同步功能已实现”和“云端日更尚未上线”。没有配置内容服务地址时不会把本地内容误报为新生成内容。
- 不再在打开手机 App 时自动调用模型 API；手动生成入口保留为高级功能。维护者 API key 不在安装包内。

## 当前未上线的功能

浙江完整版的每日云端生成及内容分发、会员、支付和付费校验均尚未上线。本次只发布安装包和版本说明，没有声称已实现每天自动更新或付费后才能使用；没有读取仓库 Secrets，也没有执行额外的付费模型请求。

现有开源版源码、MIT 许可、已有公开内容库、历史源码压缩包和更新任务全部保留。完整版源码暂未公开。GitHub 自动附带的 Source code 下载是开源版仓库源码，不是完整版源码。

## 安装和验证

- Android 包名：`cn.gongkao.guide`；版本：`1.1-full` / `versionCode 2`。
- 最低 Android 7.0。测试 APK，不是商业上架发行包。
- 与原浙江完整版签名一致，可作为原版升级包；与开源版包名不同，因此可以同时安装，而不是覆盖开源版。
- 安装前先导出学习记录备份。已做本地与浏览器测试，但尚未验证真实手机安装；不同版本的学习记录不会自动互相迁移。
